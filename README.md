# lp-goodbe-campestre

Landing page da unidade **GoodBe Campestre** (Rua das Figueiras, 1791 — Campestre, Santo André/SP).
HTML único portátil (fotos e logos embutidos em base64), servido por nginx:alpine.
Mesmo design/template aprovado da Altino Arantes.

- Deploy: Easypanel Server 1, projeto `site`, serviço `lp-goodbe-campestre` (build por Dockerfile, autoDeploy).
- WhatsApp: (11) 2577-2860 (variável `WHATSAPP` no fim do index.html).
- Fotos: ZIP do Drive da unidade (só as marcadas Campestre; o ZIP também trazia Saúde e Santa Cruz, ignoradas).
- Planos: tabela da rede (259,90 / 339,90 / 399,90).
